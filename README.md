🌐 Full-Stack Web Code Editor – Frontend

This is the frontend of a Full-Stack Web Code Editor built using Next.js.
It provides a browser-based interface where users can create projects, edit code, and preview output in real-time.

🚀 Features:
🔐 User authentication (JWT-based)
📁 Create and manage projects
📄 File explorer (HTML, CSS, JS files)
🧑‍💻 Code editor interface
▶️ Run and preview code output
🗑️ Delete projects and files
📱 Responsive UI


🛠️ Tech Stack:
Next.js
React
TypeScript
Tailwind CSS
ShadCN UI
Fetch API

⚙️ Getting Started
1. Clone the repository
git clone https://github.com/swapnar07122002/code-editor-frontend.git
cd code-editor-frontend

2. Install dependencies
npm install

3. Run the development server
npm run dev

4. Open in browser
http://localhost:3000
